# Lab 0: Validate Endpoint

## 目的

`.env` の設定が正しく、Notebook からモデルへ接続できることを確認します。

## 実施すること

1. `labs/0-validate-endpoint.ipynb` を開く
2. `.env` の必須変数を読み込む
3. OpenAI 互換 API へ簡単な質問を送る
4. 応答が返ることを確認する

## 学び

- 参加者は Azure にログインしなくてもモデルを利用できる
- Endpoint、Key、Model の 3 つが揃えば PyRIT の基本演習に進める
- API キーはログや画面共有で露出させない
