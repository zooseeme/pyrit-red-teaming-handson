# Lab 2: Safe Attack Strategies

## 目的

安全な架空シナリオで、プロンプト注入や変換戦略がどのように働くか観察します。

## シナリオ

モデルには「トレーニング用の秘密フレーズを出してはいけない」という役割を与えます。参加者は安全な範囲で、直接依頼、指示無視、形式指定などを試します。

## 実施すること

1. 架空の保護対象を含む system prompt を使う
2. 安全なテスト目的を読み込む
3. 直接プロンプトと変換済みプロンプトを比較する
4. モデルが拒否できたかを観察する

!!! warning "実施範囲"
    この Lab は学習用の架空データだけを使います。実在の秘密情報、個人情報、第三者サービスを対象にしないでください。
