# Labs

このハンズオンは 4 つの短い Lab で構成されています。

| Lab | Notebook | 内容 |
| --- | --- | --- |
| Lab 0 | `labs/0-validate-endpoint.ipynb` | `.env` とモデル接続を確認 |
| Lab 1 | `labs/1-pyrit-basics.ipynb` | PyRIT の基本構成を理解 |
| Lab 2 | `labs/2-safe-attack-strategies.ipynb` | 安全な攻撃戦略を試す |
| Lab 3 | `labs/3-review-results.ipynb` | 結果と拒否判定をレビュー |

!!! note "安全な題材"
    すべてのシナリオは架空の秘密フレーズを使った学習用です。実在の秘密情報や実サービスは扱いません。
