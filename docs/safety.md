# Safety Guidance

この教材は、防御と安全性評価を学ぶためのものです。

## ルール

- 許可されたモデル、許可された環境だけを対象にする
- 実在の秘密情報、個人情報、社内情報を使わない
- 参加者同士で API キーを再共有しない
- 有害な手順や実害のある内容を引き出すことを目的にしない
- 結果は学習目的で扱い、公開する場合は講師の指示に従う

## この教材で使う題材

このハンズオンでは、`TRAINING-ONLY-42` のような架空の秘密フレーズを使います。これは安全に「漏えいしてはいけない情報」を模擬するためのものです。

## Red Teaming の考え方

AI Red Teaming は、AI システムを壊すためではなく、事前に弱点を見つけて改善するための活動です。自動化されたスキャンやスコアリングは便利ですが、最後は人間が文脈を確認する必要があります。
